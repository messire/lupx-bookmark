# Ideas

Possible features, not a plan or a commitment.

## Bookmarks

- Import from Chrome bookmarks (one-off, by folder).
- Global search and filter over saved cards.
- Pinned "most visited" group built from history.
- Multi-select: move or delete several cards at once.
- Dead-link check with a mark on unreachable cards.

## Layout and look

- Drag-and-drop for groups again, with keyboard alternative.
- Per-group card style and background.
- Custom card icons (upload or emoji).
- Clock, weather or a quote widget, off by default.

## Data

- Optional sync through `chrome.storage.sync` within its quota.
- Scheduled automatic local backups.
- Versioned settings schema with migrations.

## Platform

- Firefox and Edge builds from the same code.
- Release automation: version bump, zip and Web Store upload from CI.
- Localization (EN/RU).
