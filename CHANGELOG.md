# Changelog

## [1.3.0] — 2026-07-19

- Settings panel split into tabs.
- Configurable number of group columns (1–4).
- Bookmark editing modal (title and URL).
- Backup tab: export/import to JSON with merge or replace.
- Empty search opens the selected engine's home page.

## [1.2.0] — 2026-07-03

- Group order changed with up/down buttons instead of drag-and-drop.
- Favicon fallback chain reworked, with refresh and no redundant probes.

## [0.1.0] — 2026-05-29

First Chrome Web Store release.

- Bookmark grid in accordion groups with drag-and-drop cards.
- 9 card styles, custom backgrounds and wallpaper gallery.
- Search bar for Google, Yandex and DuckDuckGo.
- Fixes: saving bug, favicon errors. Privacy policy added.
